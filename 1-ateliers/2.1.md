# Atelier 2.1 : les composants

## Warning

**La gestion des événements dans cette exercice n'est pas demandée, l'objectif principal est de créer des composants et les importer pour les utiliser ailleurs. Si vous souhaitiez gérer les événements une aide est proposée ci-dessous**

## Enoncé

1. Créez un nouveau projet VueJS

2. Créez au moins 4 composants pour réaliser une page panier dans l'application
- Composant produit contenant :
    - Un titre
    - Une description
    - Un prix
    - une photo
    - Quantité
- Un composant pour calculer le total du panier contenant : 
    - Le titre "Total"
    - Le sous-total
    - Le montant de la livraison
    - Le total
- Un composant livraison contenant :
    - Une liste de point relais
    - Le tarif
- Un composant pour le paiement contenant :
    - Un bouton "Paiement"
    - Une liste de moyens de paiement
3. Dans le fichier /src/App.vue, supprimez les composants présents et remplacez-les par les composants ci-dessus.


## Bonus

4. Partagez les informations entre /src/App.vue et les composants filles.

## Aides si vous voulez déjà manipuler les événements

- Modification de la quantité

```javascript
<script setup>
const emit = defineEmits(['update-quantity'])
function changeQuantity(delta) {
  emit('update-quantity', product.id, delta)
}
</script>
<template>
    <div>
        <button type="button" @click="changeQuantity(-1)">-</button>
        <span>{{ product.quantity }}</span>
        <button type="button" @click="changeQuantity(1)">+</button>
    </div>
</template>
```

- Sélection du transporteur

```javascript
<script setup>
const emit = defineEmits(['select-relay'])

function onSelect(event) {
  emit('select-relay', event.target.value)
}
</script>
<template>
    <div>
      <label
        v-for="relay in relayPoints"
        :key="relay.id"
      >
        <input
          type="radio"
          name="relayPoint"
          :value="relay.id"
          :checked="relay.id === selectedRelayId"
          @change="onSelect"
        />
        <span>
          <strong>{{ relay.name }}</strong> — {{ relay.address }}
        </span>
      </label>
    </div>
</template>
```

- Le paiement

```javascript
<script setup>
const emit = defineEmits(['select-method', 'submit-payment'])
</script>
<template>
    <div>
      <label
        v-for="method in paymentMethods"
        :key="method.id"
      >
        <input
          type="radio"
          name="paymentMethod"
          :value="method.id"
          :checked="method.id === selectedMethod"
          @change="emit('select-method', method.id)"
        />
        <span>{{ method.label }}</span>
      </label>
    </div>

    <button
      type="button"
      @click="emit('submit-payment')"
    >
      Paiement ({{ total.toFixed(2) }} €)
    </button>
</template>
```

- Les totaux

```javascript
<script setup>
const deliveryFee = computed(() => {
  const relay = relayPoints.value.find((r) => r.id === selectedRelayId.value)
  return relay ? relay.fee : 0
})

const subtotal = computed(() => {
  return cartItems.value.reduce((sum, item) => sum + item.price * item.quantity, 0)
})

const total = computed(() => {
  return subtotal.value + deliveryFee.value
})
</script>
```
