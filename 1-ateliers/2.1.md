# Atelier 2.1 : les composants

## Enoncé

1. Créez un nouveau projet VueJS
2. Créez au moins 4 composants pour réaliser une page panier dans l'application
- Composant produit contenant :
    - Un titre
    - Une description
    - Un prix
    - une photo
    - Quantité
- Un composant pour calculer le total du panier contenant : 
    - Le titre "Total"
    - Le sous-total
    - Le montant de la livraison
    - Le total
- Un composant livraison contenant :
    - Une liste de point relais
    - Le tarif
- Un composant pour le paiement contenant :
    - Un bouton "Paiement"
    - Une liste de moyens de paiement
3. Dans le fichier /src/App.vue, supprimez les composants présents et remplacez-les par les composants ci-dessus.


## Bonus

4. Partagez les informations entre /src/App.vue et les composants filles.
