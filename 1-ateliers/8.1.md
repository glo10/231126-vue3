# Atelier 8.1 : contact support

1. Copiez/collez la correction ou votre travail sur l'atelier [7.1](./corrections/7.1/) et renommez-le en 8.1

2. Créez un nouveau composant enfant exclusivement dédié au support avec un formulaire de contact possèdant les champs suivants :

- Titre : chaîne de caractères
- Email du client : chaîne de caractères
- Type de demande : une liste fermée dont les valeurs possibles sont :
    - bug
    - reclammation
    - ma commande
    - facture
    - livraison
    - mon compte
    - mes accès
    - autre
- Le niveau d'urgence : un booléen urgent ou non urgent
- Le message : un grand champ libre (chaîne de caractères)

3. A l'aide d'une librairie externe ou d'une implémentation manuelle, controlez les données saisis avant la soumission du formulaire

## Bonus

4. Créez un composant enfant pour la connexion d'un utilisateur avec les champs :
- email
- mot de passe

5. Contrôlez les données saisies avant la soumission du formulaire

6. Créez un composant enfant pour l'inscription d'un utilisateur avec les champs :
- nom
- prénom
- email
- mot de passe
- confirmation de mot de passe
- pays
- ville

7. Contrôlez les données saisies avant la soumission du formulaire
