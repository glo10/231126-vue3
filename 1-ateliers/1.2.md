# Atelier 1.2 : Vue avec une installation via NPM (Node Package Manager)

## Enoncé

1. Suivez [ce guide](https://vuejs.org/guide/quick-start.html#creating-a-vue-application) pour créer une application avec ***NPM***.

En répondant aux questions posées dans le terminal, par les réponses proposées ci-dessous :
- TypeScript? ***No***
- JSX Support? ***No***
- Vue Router for Single Page Application development? ***Yes ou cochez la ligne en naviguant avec les flèches haut/bas et en tapant sur la touche `espace`***
- Pinia for state management? ***Yes ou cochez la ligne en naviguant avec les flèches haut/bas et en tapant sur la touche `espace`***
- Vitest for Unit testing? ***No***
- an End-to-End Testing Solution? ***No***
- ESLint for code quality? ***Yes ou cochez la ligne en naviguant avec les flèches haut/bas et en tapant sur la touche `espace`***
- Prettier for code formatting? ***Yes ou cochez la ligne en naviguant avec les flèches haut/bas et en tapant sur la touche `espace`***
- Vue DevTools 7 extension for debugging? (experimental)? ***Yes ou cochez la ligne en naviguant avec les flèches haut/bas et en tapant sur la touche `espace`***

2. Finalisez votre configuration en tapant sur la touche 'ENTRER' en choisissant le gestionnaire ***NPM** et repondez oui pour avoir le projet d'exemple.

3. Suivez les instructions dans le terminal pour installer les dépendances et lancer un serveur en développement.

4. Dans le fichier *src/components/HelloWorld.vue*, dans la partie dédiée au script (entre les balises `<script></script>` plus précisément dans la méthode *defineProps*), déclarez 2 variables `question` et `response` de type *string* et *required*

5. Toujours dans le fichier *src/components/HelloWorld.vue*, dans la partie dédiée au html entre les balises `<template></template>` et au sein du conteneur `<div></div>` affichez deux paragraphes (une pour la question et l'autre la réponse) en utilisant `{{ }}`

6. Dans le fichier *src/App.vue*, dans la balise `<HelloWorld>`, ajoutez en tant qu'attributs les variables et les valeurs pour la question et la réponse.
Appuyez-vous sur l'exemple avec la variable `msg`
