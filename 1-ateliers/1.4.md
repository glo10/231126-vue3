# Atelier 1.4 : utilisation de VUE-CLI en maintenance

## Enoncé

1. Suivez [ce guide](https://cli.vuejs.org/#getting-started) pour installer et créer une application avec ***Vue-CLI***.

- PS: remplacez *my-project* par le nom de votre dossier.

A la première question, reponsez :
- ***Default ([vue 3] babel, eslint)***

2. Suivez les instructions dans le terminal pour installer les dépendances et lancer un serveur en développement.

3. Dans le fichier *src/components/HelloWorld.vue*, dans la partie dédiée au script (entre les balises `<script></script>` plus précisément au sein de l'objet  *props*), déclarez 2 variables `question` et `response` de type *String*

4. Toujours dans le fichier *src/components/HelloWorld.vue*, dans la partie dédiée au html entre les balises `<template></template>` et au sein du conteneur `<div></div>` affichez deux paragraphes (une pour la question et l'autre la réponse) en utilisant `{{ }}`

5. Dans le fichier *src/App.vue*, dans la balise `<HelloWorld>`, ajoutez en tant qu'attributs les variables et les valeurs pour la question et la réponse. Appuyez-vous sur l'exemple avec la variable `msg`
