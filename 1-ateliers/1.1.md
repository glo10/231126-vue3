# Atelier 1.1 : utilisation de Vue via le CDN

## Aides

- Pour lancer votre fichier index.html, installez l'extension Live Server depuis l'éditeur VSCode.
- Après l'installation, ouvrez le fichier index.html depuis l'éditeur, vous verrez dans la barre d'en bas et à droite "Go live", cliquez dessus pour lancer votre application depuis l'URL `http://localhost:5500`

## Enoncé

1. En vous appuyant sur l'exemple du cours, créez une application Vue JS à partir du [CDN](https://unpkg.com/vue@3/dist/vue.global.js) et d'un fichier index.html contenant votre code.
Avec une CDN, une variable globale *Vue* est disponible depuis le CDN.
