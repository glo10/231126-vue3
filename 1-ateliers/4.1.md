# Atelier 4.1 : commande

## Modalités

- **Un seul composant enfant qui gère tout**

## Enoncé

1. Créez un nouveau projet VueJS

2. Créez un composant enfant et ajoutez le support d'aide dont le template contient un titre h2 et un paragraphe par exemple
"Contactez le support en indiquant votre identifiant de commande"

3. Toujours sur le même composant enfant, ajoutez un bouton qui affiche ou masque l'aide, tels que 
```html
<button type="button" @click="showHelp = !showHelp">
    {{ showHelp ? "Masquer l'aide" : "Besoin d'aide ?" }}
</button>
```

4. Toujours sur le même composant enfant, ajoutez les informations d'une commande avec les données suivantes :
- `Identifiant` : chaîne de caractères
- `statut` : chaîne de caractères, une énumération (liste fermée) dont les valeurs possibles sont ***en attente de paiement, payée, expédiée, livrée ou annulée***
- `Client` : un objet qui répresente un client [cf. atelier 3.2](./3.2.md#enoncé)
- `Livraison` : chaîne de caractères
- `Transporteur` : chaîne de caractères, une énumération ***'Colissimo', 'UPS', 'Mondial Relay' ou 'Chronopost'***
- `Date d'estimation de la livraison` : chaîne de caractères
- `Raison de l'annulation` : chaîne de caractères

5. Toujours sur le même composant enfant, créez un simulateur de statut (voir l'exemple ci-dessous) pour afficher un message dédiée selon la valeur du statur. Par exemple, le statut a le valeur livrée, le message affiché est "Votre commande a été livrée par le transporteur UPS", etc. Si le statut est inconnu, affichez un message spécifique.
```html
<label for="status">Simuler un statut : </label>
    <select id="status" v-model="order.status">
    <option value="pending">En cours de traitement</option>
    <option value="paid">Payée</option>
    <option value="shipped">Expediée</option>
    <option value="delivered">Livrée</option>
    <option value="cancelled">Annulée</option>
    <option value="-1">Inconnue</option>
</select>
```

6. Toujours sur le même composant enfant, affichez un titre h3 avec un fond rouge uniquement lorsque la commande a été annulée avec la raison de l'annulation

7. Enfin, toujours sur le même composant enfant, affichez la date d'estimation de la livraison et le transporteur uniquement lorsque le statut de la commande vaut expédiée
