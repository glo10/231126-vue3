# Atelier 8, 9, 10 et 11 : formulaire, navigation et store

## Etape 1 : formulaire de contact pour le support

1. Mettez en place un formulaire pour contacter le support en effectuant une vérification des données à envoyer avant la soumission.
Le formulaire contient les champs suivants :
- Titre : chaîne de caractères
- Email du client : chaîne de caractères
- Type de demande : une liste fermée dont les valeurs possibles sont :
    - bug
    - reclammation
    - ma commande
    - facture
    - livraison
    - mon compte
    - mes accès
    - autre
- Le niveau d'urgence : un booléen urgent ou non urgent
- Le message : un grand champ libre (chaîne de caractères)

## Etape 2 : Envoyer une requête vers un serveur distant


2. Récupérez le fichier [server.mjs](./ressources/9.1/server.mjs) et lancez le depuis un terminal en exécutant la commande ci-après permettant de lancer le serveur qui va traiter les données envoyées via le formulaire de contact :
```bash
node /chemin/vers/le/fichier/server.mjs
```

Le serveur tourne sur le PORT 3000 et dispose de 2 routes :
- GET /admin/tickets : pour voir les tickets
- POST /support pour soumettre un ticket
    - Les données à envoyer doivent être au format JSON et exactement avec les clés exposées ci-dessous :
```json
{
    "title" : "titre saisi par l'utilisateur",
    "email": "email saisi par l'utilisateur",
    "urgent": "valeur true or false",
    "message": "message saisi par l'utilisateur"
}
```

3. Gérez la soumission des données du formulaire de support au serveur Node depuis votre composant Vue dédié

## Etape 3 :  navigation via vue-router

**Attention votre application sera cassé car les composants n'auront les données attendues, ne cherchez pas à corriger les erreurs. Dans l'étape 4 ci-après, la gestion sera à faire dans les stores avec Pinia**

4. Mettez en place une navigation en créant des pages qui seront stockées dans le dossier `/src/views`.

Vous devez avoir au moins les pages suivantes :
- Page d'accueil avec un menu de navigation pour accéder aux autres pages
- Page du formulaire de support
- Page pour visualiser une commande
- Page pour voir les produits
- Page pour voir un produit en détails
