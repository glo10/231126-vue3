# Atelier 10.1 : menu de navigation

## Enoncé

1. Créez un nouveau projet VueJS en cochant l'option **vue-router** à la création du projet.

2. Copiez/collez vos composants enfants de l'atelier précédent et refactorisez l'application pour créer des pages dédiées à chaque thématique

3. Créez un composant enfant dédié au menu de navigation

4. Testez la navigation entre les différentes pages

5. Mettez en place, une navigation imbriquée sur la page d'un utilisateur de sorte :
- /user/id/ ramène sur la page de l'utilisateur avec ses informations clés
- /user/id/adress dont le lien est accessible depuis la page précédente d'accéder à une page avec les informations uniquement sur l'adresse
- /user/id/company dont le lien est accessible depuis la page /user/id permet d'accéder à une page avec les informations uniquement sur son entreprise

**PS : id est dynamique**
