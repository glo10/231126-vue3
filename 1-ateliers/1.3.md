# Atelier 1.3 : installation de Vue via Vite

## Enoncé

1. Créez un nouveau projet Vue à partir de Vite et de la commande suivante :
```bash
npm create vite@latest 1.3 -- --template vue
```

2. Dans le fichier *src/components/HelloWorld.vue*, dans la partie dédiée au script entre les balises `<script></script>`, déclarez 2 tout simplement deux variables sans utiliser `ref()` pour stocker une question et la réponse correspondante.

3. Toujours dans le fichier *src/components/HelloWorld.vue*, dans la partie dédiée au html entre les balises `<template></template>` et au sein du conteneur `<section id="center"></section>` affichez deux paragraphes (une pour la question et l'autre la réponse) en utilisant `{{ }}`
