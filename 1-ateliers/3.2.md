## Aide sur la structure de base de l'Options API

### Composant enfant

```vue
<template>
    <p>Compteur {{ compteur }} </p>
    <button @click="envoyerAuParent">
        Ajouter 1
    </button>
</template>

<script>
export default {
  props: {
    compteur: Number
  },
  // Déclaration des événements émis
  emits: ['incrementer'],
  methods: {
    envoyerAuParent() {
      // Déclenche l'événement 'incrementer' et passe '1' en paramètre au parent
      this.$emit('incrementer', 1);
    }
  }
};
</script>

```

## Enoncé

1. Créez un nouveau projet VueJS exceptionnellement avec Vue-cli pour avoir la structure de base de l'Options API.

2. Créez un composant enfant pour gérer l'offre, un ***tableau d'objets*** dont chaque élément est composé des données reactives suivantes :

- `Reférence` : chaîne de caractères
- `Nom de l'offre` : chaîne de caractères
- `Prix mensuel` : nombre
- `Devise`: un caractère (€)
- `Nombre d'utilisateurs` : nombre
- `Support` : booléen (vrai ou faux)
- `Promo` :  chaîne de caractères avec du HTML, par exemple, `<span>Offre lancement : <strong>-50%</strong> le 1er mois</span>`

3. Ajoutez un sélecteur qui affiche tous les offres disponibles.

4. Dans le composant enfant dedié à l'offre, affichez le **Récapitulatif de l’offre**  avec les informations affichées qui se mettent automatiquement à jour selon l'offre choisit dans le sélecteur.

5. Calculez et affichez directement le sous-total en fonction du nombre d'utilisateurs par exemple : *sous-total 150 € / mois pour 5 utilisateurs*.

6. Affichez directement selon la valeur du support, *Inclus (+39 €)*  s’il est activé, sinon *Standard (inclus)*.
