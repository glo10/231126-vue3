# Atelier 3.2 : configurateur d'abonnement

## Modalités

- ***Si vous avez travaillé précédemment avec l'Option API, pour celui-ci, travaillez avec la Composition API, vice-versa.***
- **Utilisez les directives `v-text`, `v-html` et `v-once`**
- **Utilisez `data()`, `ref()` et `reactive()`**

## Enoncé

1. Créez un nouveau projet VueJS
2. Créez un composant enfant de l'offre, un tableau dont chaque élément est composé des données reactives suivantes :

- `Reférence` : chaîne de caractères
- `Nom de l'offre` : chaîne de caractères
- `Prix mensuel` : nombre
- `Devise`: un caractère (€)
- `Nombre d'utilisateurs` : nombre
- `Support` : booléen (vrai ou faux)
- `Promo` :  chaîne de caractères avec du HTML, par exemple, `<span class="badge-promo">Offre lancement : <strong>-50%</strong> le 1er mois</span>`

3. Créez un composant enfant pour le client qui manipulent les données suivantes :
- `client` : un objet avec les propriétés suivantes :
    - `nom`: chaîne de caractères
    - `prenom`: chaîne de caractères
    - `adresse` : un objet avec les propriétés `Numéro de rue`(nombre), `Nom de la rue` (chaîne de caractères), `Code postal` (chaîne de caractères), `Ville` (chaîne de caractères) et `Pays` (chaîne de caractères)
    - `code promo`: chaîne de caractères

4. Dans le composant enfant dedié à l'offre, affichez le **Récapitulatif de l’offre**  avec les informations de l'offre choisit par le client.

5. Calculez et affichez directement le sous-total en fonction du nombre d'utilisateurs par exemple : *sous-total 150 € / mois pour 5 utilisateurs*.

6. Affichez directement selon la valeur du support, *Inclus (+39 €)*  s’il est activé, sinon *Standard (inclus)*.

7. Affichez les informations du  client.
