## Etape 8 : formulaire de contact pour le support

4. Mettez en place un formulaire pour contacter le support en effectuant une vérification des données à envoyer avant la soumission.
Le formulaire contient les champs suivants :
- Titre : chaîne de caractères avec **au moins 15 caractères**
- Email du client : chaîne de caractères au format conventionnel
- Type de demande : une liste fermée dont les valeurs possibles sont :
    - bug
    - reclammation
    - ma commande
    - facture
    - livraison
    - mon compte
    - mes accès
    - autre
- Le niveau d'urgence : un booléen urgent ou non urgent
- Le message : un grand champ libre (chaîne de caractères) avec **au moins 30 caractères**


5. Récupérez le fichier [server.mjs](./ressources/9.1/server.mjs) et lancez le depuis un terminal en exécutant la commande ci-après permettant de lancer le serveur qui va traiter les données envoyées via le formulaire de contact :
```bash
node --watch /chemin/vers/le/fichier/server.mjs
```

**PS: /chemin/vers/le/fichier/server.mjs à remplacer par votre réel chemin par exemple /bureau/node-server/server.mjs ou encore ./src/server.mjs, etc.**

Le serveur tourne sur le PORT 3000 et dispose de 2 routes :
- GET /admin/tickets : pour voir les tickets
- POST /support pour soumettre un ticket
    - Les données à envoyer doivent être au format JSON et exactement avec les clés exposées ci-dessous :
```json
{
    "title" : "titre saisi par l'utilisateur",
    "email": "email saisi par l'utilisateur",
    "urgent": "valeur true or false",
    "message": "message saisi par l'utilisateur",
    "type": "reclammation"
}
```

6. Gérez la soumission des données du formulaire de support au serveur Node depuis votre composant Vue dédié
