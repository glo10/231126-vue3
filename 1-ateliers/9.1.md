# Atelier 9.1 : refactoring

## Enoncé

1. Copiez/collez la correction ou votre travail sur l'atelier [8.1](./corrections/8.1/) et renommez-le en 9.1

2. Decomposez votre application en plusieurs composants enfants et utilisez les méthodes du cours pour transmette les informations entre les composants

3. Créez un nouveau composant enfant qui liste des utilisateurs récupérés depuis l'API externe [https://jsonplaceholder.typicode.com/users](https://jsonplaceholder.typicode.com/users)

## Bonus

4. Récupérez le fichier [server.mjs](./ressources/9.1/server.mjs) et lancez le depuis un terminal en exécutant la commande :
```bash
node /chemin/vers/le/fichier/server.mjs
```

PS : **remplacez `/chemin/vers/le/fichier/server.mjs` par le chemin réel en local vers ce fichier**

5. Effectuez une requête fetch pour soumettre les informations qui seront stockées en local sur votre poste dans un fichier .json des tickets de support des utilisateurs (soumission depuis le formulaire de support d'aide)
- L'URL a interrogé est ***http://localhost:3000/support***
- Les données à envoyer doivent être au format JSON et exactement avec les clés exposées ci-dessous :
```json
{
    "title" : "titre saisi par l'utilisateur",
    "email": "email saisi par l'utilisateur",
    "urgent": "valeur true or false",
    "message": "message saisi par l'utilisateur"
}
````
